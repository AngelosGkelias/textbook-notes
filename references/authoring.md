# Authoring and attribution

## Make the reasoning usable

Write from the teaching specification rather than expanding slides in sequence. Establish the problem and intuition, develop the mechanism/model, and explain its use and limits where needed. This is a teaching logic, not a repeated section template.

Connect consequential equalities and procedural decisions to the definitions, assumptions, or mechanisms that justify them. Explain what equations mean as well as how to manipulate them. Introduce a needed prerequisite locally or link precisely to an earlier explanation before relying on it.

Choose examples that resolve a particular application gap, misconception, or boundary case. For a procedure, show input selection, applicability checks, intermediate decisions, result, and interpretation. Complete unfinished source examples under stated assumptions, or explain what missing information prevents a unique solution. Give deliberate exercises answers or solution guidance. Add recaps and self-tests only where they synthesize or test something useful.

## Preserve notation

Retain meaningful source distinctions: case, alphabet, vector/bold treatment, bars, indices, signs, reference directions, normalization, and units. Define important symbols on first use, including labels inside figures. Use a shared notation table when it helps, but keep local meanings accessible.

For conflicting conventions, state the mapping before combining results. Inspect the rendered source before treating an OCR discrepancy as an error; extraction commonly loses signs, bars, primes, and indices.

## Trace claims and corrections

Place source references near the relevant explanation, using supplied-file locations, for example “devices.pdf, PDF pp. 14–18.” Explain printed/PDF numbering differences once. Figure attribution belongs in captions as described in [visuals-and-build.md](visuals-and-build.md).

Distinguish source claims from derivations supplied by the notes, illustrative values, and externally supported additions. A scoped section note or nearby label is sufficient; a source citation must not imply that added assumptions or calculations appeared there.

Verify suspected errors against the rendered source and a reproducible check or authoritative reference. Explain confirmed corrections near the affected material and record source location, original claim, correction, evidence, and status in a compact correction register. Distinguish actual errors from extraction failures, alternate conventions, and simplifications. For ambiguity, state the chosen interpretation and uncertainty. Omit the register if there are no corrections or ambiguities.

Research a concrete gap, unfamiliar consequential addition, or conflict using relevant textbooks, primary papers/standards, or official technical documentation. Read the supporting passage and check its conditions against the course's notation and model. Record the actual edition/section/page or stable URL, and version when implementation-specific. Familiar algebra can be verified directly. If evidence is inaccessible, keep consequential unsupported claims conditional or unresolved. Never invent citations, measurements, parameters, or simulation results; label new numerical values illustrative.

## Expand existing notes

Preserve satisfactory explanations, calculations, equations, and useful figures outside the requested changes. Compare editable content where available; an unchanged input hash does not prove preservation in the new edition. For PDF-only originals that cannot be faithfully reflowed, retaining original pages and inserting clearly identified Typst teaching pages is an option. Keep navigation coherent and document deliberate corrections.
